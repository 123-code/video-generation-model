================================================================================
CLOUD GPU SETUP - COPY/PASTE COMMANDS
================================================================================

1. SSH INTO YOUR CLOUD GPU INSTANCE

2. RUN THIS (ONE COMMAND):
--------------------------------------------------------------------------------
git clone https://github.com/YOUR-USERNAME/video-generation-model.git && \
cd video-generation-model && \
chmod +x setup_cloud.sh && \
bash setup_cloud.sh
--------------------------------------------------------------------------------

3. UPLOAD VAE CHECKPOINT (from your local machine, in a new terminal):
--------------------------------------------------------------------------------
scp vae_checkpoint_epoch_24.pth user@your-gpu-ip:/path/to/video-generation-model/
--------------------------------------------------------------------------------

4. GENERATE LATENTS (on cloud GPU):
--------------------------------------------------------------------------------
python generate_latents.py
--------------------------------------------------------------------------------
This takes ~30-60 minutes depending on GPU

5. START TRAINING (on cloud GPU):
--------------------------------------------------------------------------------
cd model
python train_video_dit.py --amp --batch_size 4 --epochs 50 --save_every 5
--------------------------------------------------------------------------------

6. MONITOR TRAINING:
--------------------------------------------------------------------------------
# In another terminal/tmux window:
watch -n 2 nvidia-smi

# Check progress:
ls -lh video_dit_checkpoint_*.pth
ls -lh generated_videos/
--------------------------------------------------------------------------------

7. RUN IN BACKGROUND (optional):
--------------------------------------------------------------------------------
cd model
nohup python train_video_dit.py --amp --batch_size 4 --epochs 50 > train.log 2>&1 &
tail -f train.log
--------------------------------------------------------------------------------

8. DOWNLOAD RESULTS (from local machine):
--------------------------------------------------------------------------------
scp user@your-gpu-ip:/path/to/video-generation-model/video_dit_checkpoint_*.pth .
scp -r user@your-gpu-ip:/path/to/video-generation-model/generated_videos/ .
--------------------------------------------------------------------------------

================================================================================
COMMON GPU CONFIGURATIONS
================================================================================

16GB GPU (RTX 4060 Ti, T4):
    python train_video_dit.py --amp --batch_size 2 --dim 512 --depth 6

24GB GPU (RTX 3090, A5000):
    python train_video_dit.py --amp --batch_size 4 --dim 768 --depth 8

40GB+ GPU (A100):
    python train_video_dit.py --amp --batch_size 8 --dim 1024 --depth 12

================================================================================
TROUBLESHOOTING
================================================================================

OUT OF MEMORY:
    - Reduce batch_size: --batch_size 1
    - Reduce model size: --dim 512 --depth 4

DATASET DOWNLOAD FAILS:
    # Login to Hugging Face
    huggingface-cli login
    
    # Then download
    python download_hmdb51.py

CHECK GPU:
    nvidia-smi
    python -c "import torch; print(torch.cuda.is_available())"
